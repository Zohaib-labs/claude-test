# Bottle Crush Saga

A match-3 puzzle game with glossy glass bottles. Single file, no build step: open `index.html` in a browser.

- Swap adjacent bottles (tap two, or drag) to match 3+ of a kind
- 4 in a row -> striped bottle (clears a line); L/T shape -> bomb bottle; 5 in a row -> rainbow bottle (swap it to clear a colour)
- 20 levels with score + collect goals, 3-star ratings, leftover-move bonus
- Boosters: hammer and shuffle; hints after 5s idle; auto-shuffle when no moves remain
- Progress saved in localStorage
